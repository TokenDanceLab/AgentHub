# Hello World Web

A simple dark-themed "Hello World" web page.

## Description

This is a minimal static web project that displays a "Hello, World!" message styled with a dark color scheme. No frameworks or build tools are required.

## File Structure

```
hello-world-web/
  index.html   # Main HTML page
  style.css    # Dark theme styles
```

## How to Open

1. Navigate to the project directory.
2. Double-click `index.html` to open it in your default browser.

   Alternatively, run one of the following commands from the project directory:

   ```bash
   # macOS
   open index.html

   # Windows
   start index.html

   # Linux
   xdg-open index.html
   ```

   You can also right-click `index.html` and choose **Open with** to select a specific browser.
