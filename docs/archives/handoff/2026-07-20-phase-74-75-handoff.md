### Shell 布局（4 列 Grid）

```
┌───────┬───────────┬──────────────────┬──────────────┐
│ Rail  │ Sidebar   │   Workspace      │  Inspector   │
│ 52px  │ 180-360px │      1fr         │  48-760px    │
│       │           │                  │              │
│       │           ├──────────────────┴──────────────┤
│       │           │      Terminal Dock             │
│       │           │  grid-column: 3 / -1           │
└───────┴───────────┴─────────────────────────────────┘
```

- Rail/sidebar → `grid-row: 1 / -1`（全高，不被终端缩短）
- Terminal dock → `grid-column: 3 / -1`（仅 workspace + inspector）

- Container queries：workspace 565/470/390 分段隐藏元素

## 5. 设计 Token SSOT 地图

权威文档：`docs/architecture/07-design-system-ssot.md`

### Token 分层

| 层 | 文件 | 角色 |
|---|---|---|
| CSS token SSOT | `app/shared/src/styles/tokens-base.css` | 非主题 token（type/space/radius/elev/glass/layout/HiDPI） |
| CSS theme SSOT | `app/shared/src/styles/themes.css` | Light/dark via `data-theme` + HiDPI overlay |
| Web re-export | `app/web/src/styles/{tokens,themes,presets}.css` | `@import` shared |
| Desktop re-export | `app/desktop/src/styles/{tokens,themes,presets}.css` | `@import` shared + desktop border overrides |

### 核心 Token 族

| 族 | 前缀 | 示例值 |
|---|---|---|
| 排版 | `--font-*` / `--headline-*` / `--body` / `--label` | clamp headlines, 14/12 body/label |
| 间距 | `--sp-*` / `--space-*` (兼容) / `--wb-gap-*` | 4/8/12/16px |
| 圆角 | `--r-*` / `--radius-*` | 6/8/12/16/22/24/9999px |
| 阴影 | `--e-*` / `--elevated-card-*` | 1–4 levels |
| 动效 | `--dur-*` / `--ease-*` / `--motion-*` | 90ms–1.5s |
| 毛玻璃 | `--glass-*` (20+ tokens) | bg/border/panel/blur/elev/tint/input/shadow/text |
| 语义色 | `--primary` / `--success` / `--danger` / `--warning` / `--info` | base + bg 对 |
| 焦点 | `--ring-*` / `--focus-ring` | 2px (1x) / 3px (2x) |
| 层级 | `--z-*` | 1–700 + 特定（inspector/modal/popover） |
| 触摸 | `--touch-target-min` | 44px |
| 断点（文档） | `--bp-*` (注释) | 480/760/1024/1440/1920/2560 |

### 消费者规则（红线）

1. 新视觉值只进 `tokens-base.css` 或 `themes.css`
2. `--color-*` 是遗留/预设私有，不用在新产品 CSS
3. Product CSS 用语义 token：`--success` / `--danger` / `--primary` / `--bdr`
4. Glass 用 `var(--glass-*)` / Card `variant="glass"|"elevated"`
5. 不发明本地 `backdrop-filter` 或 rgba glass fill

## 9. 产品经理评估

> 详细版见上文对话。这里摘要供快速定向。

### 产品成熟度：**约 7/10 可依赖内部工具 · 约 6/10 可自信对外 demo**

| 强项 | 弱项 |
|---|---|
| 视觉体系 + 设计 token 分层 | Chat 主路径密度不足（日活面弱于壳） |
| 中文本土化 8/10 | Agents 页像配置中心不像产品首页 |
| 测试/CI/门禁 8.5/10 | 首次成功路径无引导 |
| 交付纪律 + 进度可审计 | 对外产品一句话定位软 |
| 多端同源 shell | Desktop vs Web 价值叙事未产品化 |

### PM 建议的优先级（非工程师视角）

**P0 — Dominate Ship 决策**：
1. Chat 主路径信息密度（transcript + inspector + composer 可读性）——**这是 rescore 明确欠分点，也是日活面**
2. Agents 页叙事——列表选 Agent 开聊，高级配置折叠或抽屉
3. 首次成功路径 E2E（空 → 装 → 聊 → 回复，中文无工程词）

**P1 — 巩固信任**：
4. P75 后 1x+2x 复评一次
5. Desktop 专属价值显性化

**三句话战略**：
1. 停止材质军备，把下个冲刺给 Chat + Inspector 密度
2. Agents 改成"可开聊的团队面板"
3. Ship 条件 = 四壳 ≥85 **且** Chat 主路径无 Block **且** 60 秒中文 demo 可录
