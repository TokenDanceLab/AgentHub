## Acceptance Notes

- A milestone is not complete because documents exist; it is complete only when the acceptance criteria in `task-breakdown.md` are verified against current files and command output.
- GITHUB_STANDARD mode stores task execution in GitHub issues and keeps `docs/progress/MASTER.md` as the local index.
- Adaptive control state lives in milestone descriptions after GitHub resource sync.
