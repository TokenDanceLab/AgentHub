# 快捷键参考

> 部分快捷键尚未全部实现，标注 🚧 的为规划中的快捷键。

---

## 全局

| 快捷键 | 功能 | 状态 |
|--------|------|:--:|
| `Ctrl+K` | 命令面板 | 🚧 |
| `Ctrl+,` | 打开设置 | ✅ |
| `Ctrl+Shift+N` | 新建线程 | ✅ |
| `F1` | 帮助面板 | 🚧 |

---

## 聊天

| 快捷键 | 功能 | 状态 |
|--------|------|:--:|
| `Enter` | 发送消息 | ✅ |
| `Shift+Enter` | 换行 | ✅ |
| `Ctrl+Enter` | 发送（带完整上下文） | 🚧 |
| `Esc` | 取消当前 Agent 执行 | ✅ |
| `↑` / `↓` | 浏览历史消息 | ✅ |
| `Ctrl+L` | 清空当前输入 | 🚧 |
| `/` | 斜杠命令 | 🚧 |

---

## 线程管理

| 快捷键 | 功能 | 状态 |
|--------|------|:--:|
| `Ctrl+Shift+N` | 新建线程 | ✅ |
| `Ctrl+W` | 关闭当前线程 | 🚧 |
| `Ctrl+Tab` | 下一个线程 | ✅ |
| `Ctrl+Shift+Tab` | 上一个线程 | ✅ |
| `Ctrl+1-9` | 切换到第 N 个线程 | 🚧 |

---

## Diff 与审批

| 快捷键 | 功能 | 状态 |
|--------|------|:--:|
| `Ctrl+Shift+A` | 批准当前 Diff | 🚧 |
| `Ctrl+Shift+R` | 拒绝当前 Diff | 🚧 |
| `Ctrl+Shift+D` | 切换 Diff 视图（Unified / Side-by-Side） | 🚧 |
| `Alt+↑` / `Alt+↓` | 在 Diff 块之间跳转 | 🚧 |

---
