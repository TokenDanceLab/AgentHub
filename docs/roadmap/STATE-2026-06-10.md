## 6. 竞品能学到但暂缓的

| 项目 | 来源 | 为什么暂缓 |
|------|------|------------|
| Matrix 协议 | metrogg | 架构选择差异——Hub-Edge 实时云同步需求下 Matrix 联邦式不合适 |
| K8s 控制平面 | metrogg | Edge lifecycle+adapter registry 已覆盖，17 文件重赛过重 |
| Manager/Worker 契约文件 | metrogg | AgentTeam 有 assignment/approval 模型，多一层契约文件是过度抽象 |
| Token 经济系统 | Toufumind | 与 AgentHub 产品方向不符（我们是协作平台不是经济系统） |
| Workflow YAML 编辑器 | Toufumind | 太重——`<ul>` 树已覆盖 TeamRun 进度可视化 |
| 多层 SSE 超时保护 | soso192 | 3 层超时设计好，但我们的 WS 已有 timeout middleware |
| Memory 自动化 | LancherM | 有趣但需要 agent memory 持久化基础设施——下版本 |
